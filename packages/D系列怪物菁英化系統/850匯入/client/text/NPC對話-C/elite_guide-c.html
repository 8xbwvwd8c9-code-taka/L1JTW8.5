【暗黑異變】古代寶石匠人

自從亞丁大陸發生暗黑異變以來，各地的怪物不僅力量暴增，甚至擁有了雙軌施法的暗黑詞綴！

但相對地，打倒牠們也將獲得帶有暗黑隨機詞綴與神秘孔洞的稀世裝備！

【裝備孔洞規則】
只有以下 9 大部位裝備擁有隨機孔洞：
‧ 武器類：隨機 0 ~ 3 洞
‧ 防具 8 部位（頭盔、身體、內衣、盾牌、手套、披風、褲子、鞋子）：隨機 0 ~ 1 洞
‧ 飾品類（戒指/項鍊/耳環/腰帶等）：固定無洞

【寶石鑲嵌說明】
雙擊背包中的五大元素寶石，游標指向目標裝備即可進行鑲嵌！若孔洞已滿，將依序由第 0 洞開始進行循環覆蓋替換。
