# BUG-850-288 — Bookmark capacity authority

STATUS=PASS_ALREADY_FIXED
LEVEL=L3
BRANCH_AUTHORITY=completed/l1jtw85-core-fixes

## Root cause

Bookmark creation used a hard-coded capacity boundary, which conflicted with the authoritative per-player expandable bookmark capacity exposed by `pc.cI()`. Players with expanded capacity could therefore be rejected by the stale fixed limit.

## Fix

Use the authoritative `pc.cI()` capacity for bookmark creation. The normalized implementation accepts creation only when current bookmark count is below that capacity; the obfuscated implementation uses the equivalent fail-closed inverse check.

Files:
- `recovery/normalized-src-vf/l1r/bh/L1BookMark.java`
- `recovered-src-obf/bh/c.java`
