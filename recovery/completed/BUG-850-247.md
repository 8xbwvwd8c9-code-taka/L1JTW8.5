# BUG-850-247 — Ranking Type 7 bucket routing

STATUS=PASS_ALREADY_FIXED
LEVEL=L3
BRANCH_AUTHORITY=completed/l1jtw85-core-fixes

## Root cause

`RankingTable` loaded character `Type=7` into the Type 3 backing bucket `q`, while the dedicated eighth-class bucket `u` was left unused. Requests for ranking type 7 therefore read `u` but its load path did not populate it.

## Fix

Route `Type=7` records to the dedicated `u` list. Types 0..6 retain their original buckets and ordering.

Normalized and obfuscated authorities are kept equivalent:

- `recovery/normalized-src-vf/l1r/ao/RankingTable.java`
- `recovered-src-obf/ao/ba.java`
