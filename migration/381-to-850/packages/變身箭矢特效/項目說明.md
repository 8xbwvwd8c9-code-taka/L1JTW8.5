## 2. 功能描述
指定特定 polymorph 外觀時，覆寫玩家的箭矢視覺特效（`polyarrow` 欄位）。

### 核心邏輯（381 donor）
```
ArrowGfxid.forItemUSe(user, poly):
  若玩家無技能特效 67 → polyarrow = 0
  若 poly == 設定的 polyid(6611) → polyarrow = arrowgfxid(8121)
  否則 → polyarrow = 66（fallback）
```

### 資料現況
- SOURCE_ROWS = **1**（單一映射：poly 6611 → arrowgfxid 8121）
- CREATE schema NOT_PROVEN
- 下游消費者（getpolyarrow / setpolyarrow → 遠端攻擊封包）**尚未封閉**
