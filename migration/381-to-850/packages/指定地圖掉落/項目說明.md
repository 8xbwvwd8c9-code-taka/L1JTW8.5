## 2. 功能機制與規則

1. **指定地圖專屬掉落 (Designated Map Drop)**：
   - 怪物在特定地圖（`mapid > 0`）被擊殺時，觸發該地圖綁定的專屬掉落池（例如傲慢之塔各樓層掉落移動卷軸與傲慢證明、巨蟻洞穴掉落螞蟻證明、奇岩地監掉落奇岩證明等，共 515 筆專屬設定）。
2. **全地圖通用掉落 (Global Map Drop)**：
   - 掉落表中 `mapid = -1`（或 `0`）設定為**全地圖通用掉落池**。
   - 任何地圖上的怪被擊殺時，系統除判定該地圖專屬池外，亦一併結算全地圖掉落池。
3. **掉落率與金幣倍率繼承**：
   - 繼承伺服器全域掉落倍率 (`Config.F`)、金幣倍率 (`Config.E`) 與地圖倍率 (`MapsTable.b(mapid)`)。
4. **DB 開關與控制**：
   - `_config` 控制參數：
     - `MapDesignatedDropSwitch`：指定地圖掉落總開關（預設 1 開啟，0 關閉）。
     - `GlobalMapDropSwitch`：全地圖掉落池開關（預設 1 開啟，0 關閉）。

## 3. 資料庫 Schema 設計

### 3.1 規則表：`w_map_designated_drop` (InnoDB, utf8)
```sql
CREATE TABLE IF NOT EXISTS `w_map_designated_drop` (
  `id` int(10) unsigned NOT NULL AUTO_INCREMENT,
  `mapid` int(5) NOT NULL COMMENT '地圖編號 (-1=全地圖通用掉落池, >0為指定地圖)',
  `itemid` int(10) NOT NULL COMMENT '掉落道具ID',
  `min` int(5) NOT NULL DEFAULT 1 COMMENT '最小掉落數量',
  `max` int(5) NOT NULL DEFAULT 1 COMMENT '最大掉落數量',
  `chance` int(7) NOT NULL DEFAULT 1000000 COMMENT '掉落機率 (基數1,000,000，例如 50000 = 5%)',
  `enchantlvl` int(5) NOT NULL DEFAULT 0 COMMENT '初始強化等級',
  `bless_change` int(3) NOT NULL DEFAULT 0 COMMENT '祝詛狀態機率',
  `note` varchar(100) NOT NULL DEFAULT '' COMMENT '備註說明',
  PRIMARY KEY (`id`),
  KEY `idx_mapid` (`mapid`),
  KEY `idx_itemid` (`itemid`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8 COMMENT='指定地圖與全地圖掉落表';
```
