## 2. 功能目的

實作技能稀有度等級化系統，依顏色區分技能品質：

| 顏色 | 品質 | 數值 |
|------|------|------|
| ⚪ 白色 | 普通（Common）| 0 |
| 🟢 綠色 | 高級（Advanced）| 1 |
| 🔵 藍色 | 稀有（Rare）| 2 |
| 🔴 紅色 | 英雄（Hero）| 3 |
| 🟣 紫色 | 傳說（Legendary）| 4 |
| 🟡 金色 | 神話（Mythic）| 5 |

神話級技能須透過副本、世界王掉落或多本傳說級合成，是頂級玩家終極目標。

### 非目標

- 不改變現有 `skills` 表的 `skill_level`（此為職業等級 1–8，已存在）
- 不複製 381 的技能框架；只擴充 850 原生 skills 路徑
- 不在此項目處理技能合成機制（屬另一項目）

## 4. 850 現況

### 4.1 850 DB — skills 表

**850 `skills` 表無 `grade` 欄位**（已確認）：

```sql
CREATE TABLE `skills` (
  `skill_id` int(10) unsigned NOT NULL AUTO_INCREMENT,
  `name` varchar(45) NOT NULL DEFAULT '',
  `castgfx` int(10) unsigned NOT NULL DEFAULT '0',
  `castgfx2` int(10) unsigned NOT NULL DEFAULT '0',
  `ranged` int(10) NOT NULL DEFAULT '0',
  `area` int(10) NOT NULL DEFAULT '0',
  `buffDuration` int(10) unsigned NOT NULL DEFAULT '0',
  `hpConsume` int(10) unsigned NOT NULL DEFAULT '0',
  `mpConsume` int(10) unsigned NOT NULL DEFAULT '0',
  `itemConsumeId` int(10) unsigned NOT NULL DEFAULT '0',
  `itemConsumeCount` int(10) unsigned NOT NULL DEFAULT '0',
  `reuseDelay` int(10) unsigned NOT NULL DEFAULT '0',
  `skill_level` int(10) NOT NULL DEFAULT '0',
  `id` int(10) unsigned NOT NULL DEFAULT '0',
  `damage_value` int(10) unsigned NOT NULL DEFAULT '0',
  `damage_dice` int(10) unsigned NOT NULL DEFAULT '0',
  `damage_dice_count` int(10) unsigned NOT NULL DEFAULT '0',
  `probability_value` int(10) unsigned NOT NULL DEFAULT '0',
  `probability_dice` int(10) unsigned NOT NULL DEFAULT '0',
  `attr` int(10) unsigned NOT NULL DEFAULT '0',
  `lawful` int(10) NOT NULL DEFAULT '0',
  `action_id` int(10) unsigned NOT NULL DEFAULT '0',
  PRIMARY KEY (`skill_id`)

```

850 有 242 筆技能 row（INSERT INTO \`skills\`）。

**注意**：850 DB 其他表格中存在 `grade int(2) NOT NULL DEFAULT '-1'` 欄位，但不在 `skills` 表。

### 4.2 850 核心

- `SkillsTable`：850 原生技能 loader，從 `skills` 表載入所有技能。
- `L1Skills`：850 原生技能 model。
- `grade` 欄位在 850 目前**未被 SkillsTable 讀取**（schema 中不存在）。

### 4.3 缺口

| 缺口 | 說明 |
|------|------|
| DB schema | `skills` 表缺 `grade tinyint(1) NOT NULL DEFAULT -1` |
| SkillsTable loader | 缺乏 grade 欄位讀取 |
| L1Skills model | 缺乏 grade getter/setter |
| 客戶端呼叫鏈 | 顏色顯示、技能書顏色 UI — NOT_PROVEN |

## 5. 決策

```
決策：HOLD
```

**理由**：
1. 381 DB/核心均無 grade 欄位作為直接供體；此為全新功能需求。
2. 850 DB `skills` 表需新增 `grade` 欄位，SkillsTable 和 L1Skills 需 adapt。
3. 客戶端呼叫鏈（技能書顏色顯示、合成 UI）尚未確認，client_gate 待評估。
4. 技能合成路徑（傳說→神話）為獨立項目，本項目只處理 grade schema + 讀取能力。

## 6. DB Schema 設計

### 6.1 新增欄位（最小化 extension）

```sql
-- 850匯入/db/install_skill_grade.sql
ALTER TABLE `skills`
  ADD COLUMN `grade` tinyint(1) NOT NULL DEFAULT -1
    COMMENT '-1=未分級 0=白色Common 1=綠色Advanced 2=藍色Rare 3=紅色Hero 4=紫色Legendary 5=金色Mythic'
    AFTER `action_id`;
```

### 6.2 rollback

```sql
-- 850匯入/db/rollback_skill_grade.sql
ALTER TABLE `skills` DROP COLUMN IF EXISTS `grade`;
```

### 6.3 資料 ownership

- `skills.grade` 由管理端 INSERT/UPDATE 設定，核心 **只讀**。
- 不涉及 character/player 持久化表。
- grade=-1 預設值確保向下相容（現有 242 筆技能不影響）。

### 6.4 索引

```sql
ALTER TABLE `skills` ADD INDEX `idx_grade` (`grade`);
```

合成/查詢時需依 grade 過濾，加索引。

### 匯入順序

### 相依條件

- 無其他 optional 模組相依
- 850 `skills` 表必須已存在（基線 `db/8.5.sql` 已含）

### 風險

| 風險 | 緩解 |
|------|------|
| ALTER TABLE 在大量 skills 表時 lock | MyISAM 引擎 ALTER 為 table copy，但僅 242 rows，影響微小 |
| grade 未知值傳入客戶端 | 預設 -1 不會 crash 客戶端（不顯示額外 UI） |
