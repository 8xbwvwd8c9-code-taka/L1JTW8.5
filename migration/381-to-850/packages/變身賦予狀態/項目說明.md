## 2. 功能描述

### w_變身賦予狀態（SOURCE_ROWS=0，無作用資料）
- DB 文件存在但 SQL 為空（0 bytes）
- 依稽核規則：NOT_PROVEN，非 SKIP
- 執行期擁有者、控制來源、850 等價均待確認

### w_變身賦予狀態_道具（SOURCE_ROWS=2，INSERT_ONLY）
- 包含欄位：note、gfxId、deadExp、cancellation、addStr/Dex/Con/Int/Wis/Cha、addAc、addMaxHp/Mp、addHpr/Mpr、addDmg/BowDmg/Hit/BowHit、reduction_dmg/magic_dmg、addMr/Sp、addFire/Wind/Earth/Water、addExp、Potion_Heal、PVPdmg/PVPdmgReduction、add_magic_hit、regist_stun/stone/sleep/freeze/sustain/blind
- 此為道具版（道具使用觸發）的 buff/stat 賦予，與單純「變身時」賦予狀態語義不同
- CREATE schema NOT_PROVEN

## 3. 主要語義邊界
```
w_變身賦予狀態     → 變身時直接觸發的狀態賦予（lifecycle: polymorph lifecycle）
w_變身賦予狀態_道具 → 道具使用觸發（lifecycle: item-use → buff / stat owner）
w_道具狀態         → 道具使用觸發的計時 buff（lifecycle: timed effect）
w_指定道具賦予狀態  → 裝備道具持久狀態（lifecycle: equipped item instance）
```
以上四者 stat 向量詞彙共享，但 lifecycle owner **必須獨立**。

## 5. 850 目標架構（850-first）
```
TransformationOwner（w_變身賦予狀態）
  → 變身 lifecycle apply/remove hook
  → stat modifier 向量（共享 StatModifierDefinition）

ItemUseBuffOwner 或 TimedBuffOwner（w_變身賦予狀態_道具）
  → 道具使用 hook
  → buff duration / stat modifier 向量
  → 不共用 TransformationOwner lifecycle
```
