## 2. 功能描述

### w_變身卡片能力登入（SOURCE_ROWS=64）
- 每列：解鎖 Quest ID、Polymorph ID/時間、可選消耗道具、加法 Stat 向量、HTML/action 指令
- 擁有者識別：`pc.getQuest().get_step(card.getQuestId()) != 0`
- 載入器：`ACardTable` → 模型 `ACard`
- UI/控制：`CardBookCmd`（`polycard`, `card_0`, `card_10`, `card_11`, `a1..a64`）
- Polymorph 路徑：`CardBookCmd.polycard` → 消耗設定道具 → 呼叫 381 `L1PolyMorph.doPoly`
- **LOGIN_STAT_APPLY = NOT_PROVEN**（顯示彙整已知，Login 實際加法 hook 尚未封閉）

### w_變身卡片能力組合套卡（SOURCE_ROWS=10）
- Set IDs 1..10，Quest IDs 5100..5109
- 組合解鎖：`Cards.execute()` 寫入卡片 Quest，掃描所有 `CardPolySet`，全部需求滿足則將 Set Quest 設為 step=1
- `C_LoginToServer.getCard()` 登入時循環所有解鎖卡片 + Set，**直接增量加法** 到玩家 Live stat
- SET_ONLY_MAX_VECTOR = STR9; DEX11; CON13; INT15; WIS5; CHA7
- MAX_COLLECTION_VECTOR = STR23; DEX25; CON27; INT33; WIS17; CHA7
- DONOR_INCREMENTAL=YES / DONOR_RECOMPUTE=NO → **DRIFT_RISK=HIGH**

## 5. 850 目標架構（850-first）
```
CardDefinition
  unlock quest ID
  polymorph ID + duration
  consume requirements
  stat modifier vector

CollectionOwner（與登入+套卡共用）
  authoritative unlocked quest states
  derive active sets
  recompute CollectionBonus = Σ(card vectors) + Σ(set vectors)
  stat rebuild 一次

PolymorphAction
  850 native polymorph path

Presentation
  850-native UI（保留 card 語義；不必原樣複製 donor HTML）
```

## 6. 阻斷項目
| 類型 | 說明 |
|------|------|
| DB | CREATE schema 未取得，card-id 欄位無效（全為 literal 1） |
| Core | Login/recalc stat 應用 hook 未封閉；idempotent stat recompute 未證明；DRIFT_RISK=HIGH |
