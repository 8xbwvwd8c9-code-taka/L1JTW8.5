# 敵人死亡奪寶 (enemy-death-loot)

## 企劃來源
天堂企劃.txt：`L2,w_敵人死亡奪寶,N/A`

## 功能說明
玩家死亡後，可被其他玩家搶奪身上物品的系統。  
備注：適合紅人假人，在玩家看不到的區域邊緣刷新後來追殺。

## 381 資料庫結構

**資料表：** `w_敵人死亡奪寶`

| 欄位 | 說明 |
|------|------|
| item_id | 可被奪取的物品 ID |
| note | 備注說明 |
| steal_chance | 奪取機率 (%) |
| min_steal_count | 最小奪取數量 |
| max_steal_count | 最大奪取數量 |
| is_broadcast | 是否廣播公告 |
| drop_on_floor | 是否丟落地板 |
| anti_steal_item_id | 防奪寶物品 ID (0=無) |
| level | 等級限制 |
| mete_level | 轉生等級限制 |
| dropmsg | 廣播訊息格式 |
