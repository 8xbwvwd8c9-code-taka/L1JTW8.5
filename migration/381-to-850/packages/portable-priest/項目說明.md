# 隨身祭司 (portable-priest)

## 企劃來源
天堂企劃.txt：`L2,w_隨身祭司,N/A`

## 功能說明
玩家可攜帶一名隨身祭司 NPC，自動施放指定技能（如：恢復 HP/MP 的 buff 技能）。  
提供初級/中級/高級/頂級四種等級。

## 381 資料庫結構

**資料表：** `w_隨身祭司`

| 欄位 | 說明 |
|------|------|
| npc_id | 隨身祭司的 NPC ID |
| name | 隨身祭司名稱 |
| skill_id | 施放技能 ID 列表（逗號分隔） |
| skill_mp | 各技能消耗 MP（逗號分隔） |
| note | 技能名稱備注（逗號分隔） |
