# 850 原生單一融合假人系統 (381 + 880) 完整架構規劃書

> **文件版本**：v2.0 (權威融合版)  
> **核心指示**：
> - **381 假人與 880 假人融合進 850，不需要分開**。
> - **定時會去攻打城堡、定時野外打怪**。
> - **假人具備與真實玩家完全一致之行為模式**（尋敵、走位、階梯喝水、狂奔逃跑、擺攤、逛街、回村補給）。
> - **假人建立獨立專屬血盟進行統一管理與集火協同作戰**。

---

## 1. 系統願景與設計目標

舊版架構中，381 假人著重於「攻城戰陣營作戰與皇冠摸塔流程」，880 假人則著重於「擬真度極高之打怪、走位、階梯喝水、回卷逃生與城鎮擺攤」。  
**本規劃將兩者融合成 850 原生單一假人系統（`Unified L1Robot`）**：
1. **單一系統，無分立實例**：不分 381 假人或 880 假人，所有假人均基於 850 原生架構驅動。
2. **行為狀態機（State Machine）一體化**：
   - 平時：於野外狩獵打怪、回村補給、或在城鎮安全區逛街、擺攤。
   - 攻城時段（定時觸發）：全體/特定假人切換至「攻城戰狀態機」，以專屬血盟身分集結攻打城堡（衝門、破塔、摸冠）。
3. **專屬獨立血盟統一管理**：
   - 建立系統專屬管理血盟（例如：`【闇影禁軍】` 或可配置盟名）。
   - 假人自帶專屬血盟徽章與盟名，受攻擊時自動於同盟頻道與視野內呼叫同盟假人集火反擊玩家。

## 3. 假人獨立血盟管理架構

1. **血盟專屬識別**：
   - 假人生成時自動加入由系統預先註冊之專屬管理血盟（例如：`RobotClanId = 99999`，盟名：`【王者之師】`）。
   - 頭頂顯示正式盟徽與階級稱號，與真正玩家血盟完全一致。
2. **同盟集火仇恨鏈**：
   - 當任何假人遭到玩家惡意攻擊時，觸發 `ClanCallHelp` 機制。
   - 視野（15 格）內所有同血盟之假人，立即中斷當前打怪動作，將主要目標鎖定該攻擊玩家，展開圍毆。
3. **殺人與懲罰機制**：
   - 假人擊殺玩家後，就地施放勝利煙火，並在白頻嘲諷。
   - 玩家擊殺假人正常扣除正義值（直接變紅名），若假人死亡掉落設定之真實消耗道具（如紅水、名譽金幣）。

## 4. 定時攻城機制整合 (381 SiegeWar 融入 850)

1. **時段觸發與廣播**：
   - 由設定檔設定攻城時間（例如：每週三、六晚間 20:00，或每日固定週期）。
   - 攻城開始前 5 分鐘，伺服器發布全服紅字公告：「【攻城警報】假人血盟【王者之師】已向【肯特城/奇岩城】發動宣戰！」。
2. **陣容動員與分工**：
   - 系統自野外與城鎮動員 50~100 名戰鬥型假人，直接傳送至城堡外圍攻城旗幟區。
   - 職責分配：
     - **騎士/黑妖/狂戰**：前鋒部隊，頂門輸出。
     - **妖精/弓手**：後排遠程箭雨壓制。
     - **法師**：支援放集體治癒術、加速術、聖結界。
     - **君主 (King)**：在主力保護下推進，專門負責最後摸皇冠。
3. **推進五階段（Phase Progression）**：
   - **階段一（攻破外門）**：全軍鎖定外城門（DoorInstance），阻擋之玩家予以擊殺。
   - **階段二（攻破內門）**：突破外門後，全隊沿路徑尋路（PathFinder）挺進內門。
   - **階段三（拔除守護塔）**：進入城堡核心，全軍集火守護塔（TowerInstance）。
   - **階段四（佔領皇冠）**：守護塔倒塌後，皇冠（CrownInstance）掉落，假人君主向前觸碰皇冠，系統宣佈城池易主。
   - **階段五（攻城結束）**：城堡佔領完成後，防守假人進駐內城，進攻假人解散回歸野外打怪與城鎮生態。

## 5. 資料庫 (DB) 與設定檔規範

### 5.1 資料表新增規範
1. **`w_robot_config`**：
   - 總開關、人數上限、定時攻城週期、城堡目標 ID、階梯喝水閥值。
2. **`w_robot_spawn`**：
   - 假人名字庫、性別、職業、等級範圍、預設變身外觀、配戴武器與娃娃。
3. **`w_robot_clan`**：
   - 專屬假人血盟基本資料（血盟 ID、血盟名稱、王族君主角色名、盟徽資料）。
4. **`w_robot_chat`**：
   - 喊話庫（包含打怪、被攻擊嗆聲、圍毆叫人、殺人嘲諷、回卷前廢話、攻城衝鋒號令）。

### 5.2 統一設定檔 `config/robot.properties`
整合 880 與 381 之配置項：
- `RobotSystem_Enable = true`
- `Robot_ClanName = 【王者之師】`
- `Robot_TotalCount = 800`
- `Robot_Siege_Enable = true`
- `Robot_Siege_CastleId = 1` (1=肯特, 2=妖魔, 3=風木, 4=奇岩)
- `Robot_Siege_Schedule = 20:00`
- `Robot_PotionRedRatio = 0.9` / `Robot_PotionOrangeRatio = 0.7` / `Robot_PotionWhiteRatio = 0.4`
- `Robot_FleeHpRatio = 0.25`
- `AutoSpawnDeMapMode = 1` (黑名單排除小屋與副本)
