# 項目說明 — D系列怪物菁英化系統（Monster Elite System）

## 1. 基本資訊

| 欄位 | 值 |
|------|-----|
| **項目名稱** | D系列怪物菁英化系統 |
| **別名** | Monster Elite System / 菁英怪 / Elite Monster |
| **企劃來源** | `I:\天堂企劃.txt` 第 2 條（D系列） |
| **清冊 ID** | SQL #154 `npc_202609221205.sql`（主要）；`eric_random_mob_202609221205.sql` |
| **module_id** | `D系列怪物菁英化系統` |

## 2. 功能目的

D系列副本/世界的怪物依照「世界難度」隨機生成菁英版本：

| 規則 | 值 |
|------|-----|
| 一般小怪生成機率 | **10%** 機率生成菁英版 |
| 菁英小怪血量 | **×1.3**（基礎 HP × 1.3） |
| BOSS 血量 | **不變**（維持基礎值） |
| 前綴詞墜 | 依世界難度增加一條詞墜 |
| 後綴詞墜 | 依世界難度增加一條詞墜 |
| 掉落率 | **加倍**（×2） |

### 非目標

- 不改變 BOSS 血量
- 不複製 381 的菁英框架
- 本項目不處理詞墜的具體效果（屬性系統為另一項目）
- 本項目不處理世界難度切換機制（世界難度為獨立控制）

## 4. 850 現況

### 4.1 850 DB — npc 表（完整欄位確認）

850 `npc` 表已有：
- `hp int(10) unsigned`：基礎血量
- `hard tinyint(1) unsigned DEFAULT '0'`：強化旗標
- `randomhp int(5) unsigned`：隨機血量附加值
- `damage_reduction int(5) unsigned`：傷害減免

**無** `elite_chance`、`elite_hp_mult`、`world_difficulty_tier`、`prefix_affix`、`suffix_affix` 欄位。

### 4.2 850 核心

- `MobTable` / `NpcTable`：850 原生怪物 loader
- `L1Monster`：850 怪物 model，有 `setMaxHp()`
- `SpawnTable`：850 出生點管理，無機率分支邏輯
- 無 Elite 觸發器或世界難度框架

### 4.3 缺口

| 缺口 | 說明 |
|------|------|
| 菁英生成機率 | 10% 觸發機率邏輯（SpawnTable 或 L1Monster birth） |
| 血量乘算 | 小怪 HP × 1.3（runtime 計算，非 DB 儲存） |
| 詞墜系統 | 世界難度對應前後詞墜配置 |
| 掉落率加成 | 菁英版掉落 ×2 |
| 世界難度控制 | 難度等級 → 詞墜選擇映射 |
| DB 設定表 | `w_elite_config`（難度→詞墜映射） |

## 6. DB Schema 設計

### 6.1 菁英設定表（新增）

```sql
-- 850匯入/db/install_monster_elite.sql
CREATE TABLE IF NOT EXISTS `w_elite_monster_config` (
  `id` int(10) unsigned NOT NULL AUTO_INCREMENT,
  `world_difficulty` tinyint(2) NOT NULL DEFAULT 0
    COMMENT '0=普通 1=困難 2=地獄 ...',
  `elite_spawn_chance` int(3) unsigned NOT NULL DEFAULT 10
    COMMENT '小怪生成菁英機率(%)，預設10',
  `hp_multiplier_pct` int(5) unsigned NOT NULL DEFAULT 130
    COMMENT '血量倍率(%)，130=×1.3，BOSS不套用',
  `drop_rate_multiplier_pct` int(5) unsigned NOT NULL DEFAULT 200
    COMMENT '掉落率倍率(%)，200=加倍',
  `prefix_affix_pool` varchar(255) NOT NULL DEFAULT ''
    COMMENT '前綴詞墜ID清單(逗號分隔)',
  `suffix_affix_pool` varchar(255) NOT NULL DEFAULT ''
    COMMENT '後綴詞墜ID清單(逗號分隔)',
  `note` varchar(255) NOT NULL DEFAULT '',
  PRIMARY KEY (`id`),
  KEY `idx_world_difficulty` (`world_difficulty`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8 COMMENT='D系列菁英怪世界難度設定';

-- 預設種子資料（world_difficulty=0 普通難度）
INSERT INTO `w_elite_monster_config`
  (world_difficulty, elite_spawn_chance, hp_multiplier_pct, drop_rate_multiplier_pct, prefix_affix_pool, suffix_affix_pool, note)
VALUES
  (0, 10, 130, 200, '', '', '普通難度預設'),
  (1, 10, 130, 200, '', '', '困難難度（詞墜待填入）'),
  (2, 10, 130, 200, '', '', '地獄難度（詞墜待填入）');
```

### 6.2 rollback

```sql
-- 850匯入/db/rollback_monster_elite.sql
DROP TABLE IF EXISTS `w_elite_monster_config`;
```

### 6.3 資料 ownership

- `w_elite_monster_config`：管理端設定，核心只讀
- 菁英狀態為 **runtime only**，不寫入 character/npc 表
- BOSS 判斷：`npc.hard=1` 或 npcid 範圍 → 跳過血量加成

### 6.4 交易邊界

- 菁英生成為 spawning 時 runtime 計算，無 DB transaction
- 掉落率加成在死亡事件計算，不涉及持久化

## 7. 核心 Owner / Hook

| 元件 | 職責 |
|------|------|
| `SpawnTable` 或 `L1SpawnThread` | 出生時擲骰 10%，決定是否為菁英 |
| `L1Monster` | 持有 `isElite boolean`、`eliteDropMultiplier` |
| `EliteMonsterHelper`（新增） | 封裝菁英判定、血量計算、詞墜選擇邏輯 |
| `DropTable` | 死亡時讀取 `isElite` 決定掉落率 |
| `EliteConfigTable`（新增） | 載入 `w_elite_monster_config` |

啟動流程：
```
Server start → EliteConfigTable.load() → 讀 w_elite_monster_config
怪物生成 → SpawnTable → EliteMonsterHelper.roll(10%) 
  → true: L1Monster.setElite(hp×1.3, affix[difficulty])
死亡 → DropTable.getDrop() → if(isElite) dropRate×2
```

|--------|------|--------|------|

## 10. 匯入順序、相依與驗證

### 匯入順序

1. `850匯入/db/install_monster_elite.sql`（CREATE TABLE + seed data）
2. 新增 `EliteConfigTable.java`（loader）
3. 修改 `L1Monster.java`（新增 isElite, eliteDropMultiplier）
4. 修改 `SpawnTable`/`L1SpawnThread`（10% 擲骰）
5. 修改 `DropTable`（掉落率加乘）

### 相依條件

- 世界難度系統（`world_difficulty` 值來源）為前置依賴
- 詞墜效果系統（affix 實際能力）為獨立相依
- 無其他 optional 模組隱性相依

### 風險

| 風險 | 緩解 |
|------|------|
| BOSS 誤套血量加成 | `npc.hard=1` 旗標判斷，或 BOSS npcid 清單設定 |
| 菁英狀態跨 respawn 重置 | isElite 為 runtime only，每次生成重新擲骰 |
| 10% 機率實作不一致 | 使用 Java Random 標準實作，seed 可設定 |
