# 轉生家族 (轉生系統家族)

## 企劃來源
天堂企劃.txt（3 條相關企劃合併為一個套件）：
- `L2,william_pc_轉生,N/A`
- `L2,william_pc_轉生_giveitem,N/A`
- `L2,william_pc_轉生經驗,N/A`

## 功能說明
玩家達到條件後可進行「轉生」，轉生後獲得額外屬性加成（HP/MP/STR/reduction_dmg 等），  
每次轉生消耗一定比例的經驗值，並可獲得指定物品獎勵。

## 381 資料庫結構

### 資料表 1：`william_pc_轉生`（主表）

| 欄位 | 說明 |
|------|------|
| mete_level | 轉生等級 (1~N) |
| type | 職業類型 (0=王族, 1=騎士, ...) |
| note | 職業名稱 |
| title | 轉生稱號（含格式碼） |
| ac | AC 加成 |
| hp | HP 加成 |
| mp | MP 加成 |
| hpr | HP 回復加成 |
| mpr | MP 回復加成 |
| str/con/dex/wis/cha/intel | 各屬性加成 |
| sp | SP 加成 |
| mr | 魔法抵抗加成 |
| hit_modifier / dmg_modifier | 命中/傷害修正 |
| bow_hit_modifier / bow_dmg_modifier | 弓命中/傷害修正 |
| magic_dmg_modifier / magic_dmg_reduction | 魔法傷害/減傷 |
| reduction_dmg | 物理減傷 |
| defense_water/wind/fire/earth | 四屬性防禦 |
| regist_stun/stone/sleep/freeze/sustain/blind | 各狀態抵抗 |

資料量：支援 1~20 轉（每個職業），20+ 轉後不再加 STR/reduction_dmg

### 資料表 2：`william_pc_轉生_giveitem`（轉生獎勵物品）

| 欄位 | 說明 |
|------|------|
| note | 備注 |
| logpcpower | 觸發的轉生次數 |
| getItem | 給予物品 ID |
| count | 物品數量 |


### 資料表 3：`william_pc_轉生經驗`（轉生經驗懲罰）

| 欄位 | 說明 |
|------|------|
| logpcpower | 轉生次數 |
| expPenalty | 死亡經驗懲罰比例 (0~1) |

資料量：49 筆，1轉=0.95 → 隨轉生次數遞減，後期回升
