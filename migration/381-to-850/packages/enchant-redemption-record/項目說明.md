# 衝裝贖回記錄 (enchant-redemption-record)

## 企劃來源
天堂企劃.txt：`L2,w_衝裝贖回記錄,N/A`

## 功能說明
衝裝失敗後的贖回機制，記錄各強化等級失敗後可贖回的費用/物品設定。  
NPC 提供玩家以消耗資源來取回損失裝備的服務。

## 381 資料庫結構

**資料表：** `w_衝裝贖回記錄`

| 欄位 | 說明 |
|------|------|
| id | 主鍵 |
| npcid | 提供贖回服務的 NPC ID |
| itemid | 贖回所需物品 ID |
| count | 所需物品數量 |

### 381 範例資料
```sql
INSERT INTO atu381.w_衝裝贖回記錄 (id,npcid,itemid,count) VALUES
  (0,93073,44070,10),
  (1,93073,44070,20),
  (2,93073,44070,30),
  (3,93073,44070,40),
  (4,93073,44070,50);
```

> **說明：** NPC 93073 提供贖回服務，費用物品 44070 依等級 0~4 分別需 10/20/30/40/50 個。
